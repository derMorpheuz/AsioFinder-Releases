# ASIO Finder: Downloads

**Interface anschließen, ASIO einrichten, latenzarm spielen.** · *Soundcraft by derMorpheuz*

ASIO Finder erkennt dein Audio-Interface, richtet den passenden ASIO-Treiber ein und stellt Windows auf niedrige
Latenz ein. Danach kannst du Gitarre, Bass, Keyboard oder Mikrofon direkt einspielen. Das klappt auch mit
**älteren Interfaces**, für die es keinen Treiber für Windows 11 mehr gibt (über den freien Universaltreiber FlexASIO).

## Download

➡️ **[Neueste Version](../../releases/latest)**: `AsioFinder.exe` herunterladen und starten.

- Windows 10/11, 64-Bit. Keine Installation nötig.
- Beim ersten Start zeigt Windows „Der Computer wurde durch Windows geschützt“, weil die exe nicht signiert ist:
  **Weitere Informationen → Trotzdem ausführen**.
- Das Zip enthält die exe und die ausführliche Anleitung (`README.txt`).

## Funktionen

- 🔌 Erkennung von USB-, FireWire- und PCI-Interfaces (rund 40 Hersteller, viele ältere Modelle)
- 🎛️ ASIO-Treiber finden und testen, Hersteller-Download oder Universaltreiber einrichten
- ⏱️ Puffer & Latenz in ms, Hersteller-Bedienfeld per Knopf
- 🎧 Live-Mithör-Test mit Pegelanzeige
- ⚙️ Windows-Tuning mit Rückgängig, Konfliktprüfung (Voicemeeter, Abtastraten, Akku)
- 🎹 Anleitungen für Cubase, FL Studio, Ableton, REAPER, Studio One u. v. m.
- 🔄 Aktualisiert sich automatisch

## Updates

ASIO Finder fragt beim Start und alle 12 Stunden die neueste Version hier ab und installiert sie per Klick.
Vor dem Austausch werden Größe und SHA256-Prüfsumme geprüft. Deine Einstellungen bleiben erhalten.
